# CivicSnap 

CivicSnap is a web application designed to help citizens report civic issues and contribute towards building cleaner, safer, and better communities.

## ✨ Features

- 📍 Report civic issues in your area
- 📝 Simple and user-friendly interface
- 🌐 Web-based application
- 📱 Responsive design for different devices

## 🛠️ Tech Stack

- React / TypeScript
- Vite
- Node.js and npm

## 💻 Run Locally

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd CivicSnap
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🔑 Environment Variables

If your project uses the Gemini API, create a `.env.local` file and add:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Keep your API key private. Never commit secret keys to GitHub.

## 🚀 Deployment

CivicSnap can be deployed using Vercel. Connect your GitHub repository to Vercel and configure the required build settings and environment variables.
